# 增量设计

- AttemptResult 新增默认空 diagnostics，记录响应头耗时、最近内容时间、思考/回答片段数、冻结超时与输出限额；不记录思考内容或密钥，旧记录通过已有指标推断。
- 每次启动/显式恢复使用独立 model block 集合；401/403 返回后立即阻止该模型新派发与重试，保留已经在途请求。持久化 block/resume 事件，不伪造请求、用量或评分。恢复仍遵守原重试上限与预算，已失败且无重试额度的样本不重发。
- 独立 report_views 模块读取旧/新报告相同汇总字段；正式与子集成绩明确区分，雷达只画完整维度，真实零保留、缺失不补零。以冻结名称展示模型。
- 默认全部实际请求（含失败及重试）；支持完成/未完成请求。每个 Token 指标显示有效 n、范围总数、缺失率，均值仅基于已上报值。缓存为输入的子集，采用并列柱形；输出是否含思考按报告元数据说明。
- Streamlit 使用 Plotly，HTML 使用内嵌静态 SVG、转义文本与折叠原始证据，无脚本/外部资源。报告算法 t6-v2 不变。
- UI 从独立模块导入新符号，避免旧进程模块缓存；后台改进在下一次服务加载时生效，不替换活跃 worker。
- 用户授权优化下已追加 Seed 当前配置版本：600 秒、32768 最大输出 Token，保持采样/思考/能力声明原值。所有历史冻结计划 hash 核对未变；未发请求验证成功率。
- 主入口支持 `?page=结果对比` 直接访问页面，未知页面参数回退首页。HTML 子集柱形标注“子集”，与首页口径一致；模型在各质量图表中的颜色一致。
