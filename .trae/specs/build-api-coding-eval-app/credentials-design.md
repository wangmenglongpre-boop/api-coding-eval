# 密钥持久化增补设计（2026-10-23）

用户要求优化会话密钥丢失。旧实现依赖 Streamlit session_state，重连或进程重启后会丢失，未设置环境变量引用的模型还会发送无鉴权请求。

## 保存与读取

`coding_eval/credentials.py` 通过 `keyring.backends.macOS.Keyring` 直接访问原生钥匙串，不使用可配置的 keyring 后端链，避免明文降级。service 为 `coding-eval.model-api`，account 为配置 ID、协议、URL 模式及完整服务地址的 SHA-256。模型参数变更不改变 account，服务地址变化不复用旧密钥。已删除配置/旧地址对应的遗留项目可由用户在 macOS 钥匙串访问中管理。

用户点击“保存密钥到系统钥匙串”后写入，新会话通过同一 account 自动读取。当前输入为空时可保存已有会话密钥。保存失败保留会话输入供重试，异常仅展示固定文案。删除钥匙串密钥也清除会话覆盖，单独清除会话不删除持久密钥。不会在浏览器 localStorage 或 SQLite 中保存。

优先级：显式会话密钥 > 钥匙串 > 指定环境变量。会话密钥也绑定服务地址；升级时保留现存会话输入，并在首次使用时绑定。没有原生后端时允许环境变量/会话使用；读取失败时阻断并提示解锁，不发送无鉴权请求。系统支持范围目前为 macOS，容器/远程 Linux 不能访问本机钥匙串。

## 调用与脱敏

APIClient、PlanningAgent、BatchRunner 统一解析。批次在任何请求 intent 前解析全部冻结模型并检查，解析结果只保存在 worker 的局部内存中；API 与二次存储脱敏使用同一密钥。UI 启动/恢复前同步预检，使用户立即看到具体缺失的模型，失败不保存新批次或产生探针/控制调用记录。

公网模型默认要求密钥；匿名服务可显式声明 `api_key_required=false`。loopback 和 `.invalid`/`.test` 保留测试域名默认不要求；环境变量引用/显式 true 始终要求。APIClient 将缺失返回为 configuration_error，避免产生 HTTP 401 批量失败。

保存模型配置时读取已有持久凭据及现存会话/环境凭据，阻止普通字段包含密钥。真实 API Key 不由 Agent 读取、迁移或测试写入；真实钥匙串写入由用户点击完成。

## 验证

所有框架测试隔离真实系统钥匙串。用模拟 OS backend 验证持久对象重建、Streamlit 新会话、优先级、目的地绑定、删除、权限失败、无明文降级、批次零请求预检、API/控制调用/报告脱敏。真实 OS 保存/读取的权限弹窗由用户首次使用时处理，离线测试不声称已验证真实密钥或供应商调用。
