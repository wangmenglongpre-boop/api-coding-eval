# 设计

1. 新增独立 UI 查询模块，不重载已运行 backend 类。当前版本查询只返回 heads；批量读取所选 attempts 的判分；运行摘要剔除 raw_response/raw_output；报告列表只读元信息，所选报告才反序列化。
2. 使用有明确控件的按需加载。折叠 expander 不代表惰性执行，因此原文、原始响应、JSON 编辑和报告分组增加显式开关；答案页与总览分开渲染。
3. 运行监控使用 Streamlit fragment；活跃批次默认每 3 秒刷新摘要，已结束批次默认关闭，可手动开关。监控中刚结束的批次将在下次全页交互时取消调度。绝不定时刷新付费操作或整张计划表单。
4. 使用 Streamlit 1.66 延迟 download callable，点击时在独立线程生成并下载，正常交互不编码大文件。数据与密钥不进入全局缓存；导出回调绑定所选不可变报告。
5. 应用级样式采用原生语义 DOM、轻量 CSS、浅色背景、清晰卡片与窄屏适配；不增加外部图片或脚本。
6. 主入口检查 UI 源文件 mtime，只更新 UI 与 UI 查询模块，保留 worker_registry 同一缓存资源。通过 import_module 获取注册模块，兼容旧 package alias；后台 API、存储、判分与编排类不重载。
7. 顶部与侧栏导航同步 session state 与 URL；默认侧栏收起，窄屏无需展开覆盖正文的侧栏。窄屏固定页眉下保留 4rem 间距。

验收采用真实已有数据的只读 AppTest 基准（冷/暖时间、元素字节）与真实浏览器。
单测检查 heads 回选、missing、跨库隔离、批量判分与完整详情的保真性。
